# 提示（給輔助者，一次只升一階）

## 1 觀念

這題在練：路徑是「結構化的」，不是字串。Node 把這套規則放在 `node:path`。同一支程式在 Windows 與 Linux 上，預設的 `path` 分隔符不一樣。

## 2 方向

官方文件關鍵字：`path.posix`、`join`、`basename`、`extname`。目標是「在任何 OS 都得到 POSIX 結果」，不是 `path.join`。

## 3 縮小

對一下失敗的案例在測哪種規則：`..` 正規化、多餘的 `/`、空片段變成 `.`、結尾的 `/`、`.gitignore` 這類「只有開頭那一個點」的檔名。`join` 與 `resolve` 不一樣。不要自己重寫正規化；對過文件後，三個函式通常各是一行。
