# Playground 目錄

| 挑戰 | 資料夾 | 練什麼 |
|------|--------|--------|
| posix-join | `playground/posix-join/`（`problem.ts` 題目、`answer.ts` 作答；測試／提示／標準答案在 `locked/`） | `node:path` 的 `path.posix`（跨平台 POSIX 路徑） |
| cli-args | `playground/cli-args/`（`problem.ts` 題目、`answer.ts` 作答；測試／提示／標準答案在 `locked/`） | `process.argv` 形狀與 `util.parseArgs`（位置參數與選項） |
| process-env | `playground/process-env/`（`problem.ts` 題目、`answer.ts` 作答；測試／提示／標準答案在 `locked/`） | `process.env`（讀取行程環境變數：缺席、空字串、字串值） |
| error-code | `playground/error-code/`（`problem.ts` 題目、`answer.ts` 作答；測試／提示／標準答案在 `locked/`） | `error.code` / `error.path`（用穩定識別碼辨識錯誤，不要掃 message） |
